## 功能概述

修复从系统托盘恢复窗口时页面状态不正确的问题。用户从托盘恢复窗口时，应始终显示主界面，而不是保持之前的设置页面或选择模式状态。

### 修复问题

1. **托盘恢复页面问题**：从托盘恢复窗口时，应自动切换到主界面
2. **选择模式状态问题**：从托盘恢复时，应退出选择模式状态
3. **用户体验优化**：确保用户随时可以快速访问主界面

## 功能概述

新增自动清理规则功能，提供更灵活的自动清理设置，让用户能够根据不同的条件自动清理历史记录。

### 新增功能

1. **自定义清理规则**：支持按时间、数量、大小等多种条件自动清理
2. **规则优先级**：支持设置多个清理规则的优先级
3. **规则预览**：在应用规则前预览将要清理的内容
4. **规则导入导出**：支持清理规则的导入和导出

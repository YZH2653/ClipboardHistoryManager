## 更新内容

### ✨ 新功能

#### 自动清理规则
- **功能描述**：新增自动清理规则功能，提供更灵活的自动清理设置
- **主要特性**：
  - 支持按时间清理（X天前的记录）
  - 支持按数量清理（保留最近X条记录）
  - 支持按大小清理（保留最近XMB的记录）
  - 支持混合条件（同时满足多个条件才清理）
  - 支持多个清理规则的优先级设置
  - 支持规则预览功能
  - 支持规则导入导出

### 🔧 改进优化

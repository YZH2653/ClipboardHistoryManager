# 版本 1.9.0.0 更新日志

## 版本信息

- **版本号**：1.9.0.0

- **状态**：已发布

## 更新内容

### ✨ 新功能

#### 全局快捷键支持
- **功能描述**：新增全局快捷键支持，提升操作效率
- **主要特性**：
  - Ctrl+Alt+V：快速显示/隐藏主窗口
  - Ctrl+Alt+C：快速复制最近一条文字记录
  - 主界面底部显示快捷键提示
  - 防止重复打开程序

### 🔧 改进优化

#### 用户体验
- 全局快捷键响应
- 快捷键提示显示在主界面底部
- 修复窗口显示/隐藏问题（使用 SW_RESTORE）
- 防止重复打开（使用互斥锁）

### 🐛 Bug 修复

- 修复快速复制复制旧记录的问题（现在复制最新记录）
- 修复窗口从托盘恢复时不弹出的问题
- 修复重复打开程序导致快捷键注册失败的问题

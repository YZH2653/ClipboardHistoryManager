## 功能概述

新增全局快捷键支持，提升操作效率。

### 主要功能

1. **Ctrl+Alt+V**：快速显示/隐藏主窗口
2. **Ctrl+Alt+C**：快速复制最近一条文字记录
3. **快捷键提示**：主界面底部显示快捷键说明
4. **防重复打开**：使用互斥锁防止多开

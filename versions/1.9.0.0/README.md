## 功能概述

新增全局快捷键支持，提升操作效率。

### 主要功能

1. **全局快捷键**：系统级快捷键，即使窗口不在前台也能响应
2. **快速调出窗口**：一键显示/隐藏主窗口
3. **快速粘贴**：快捷键触发粘贴操作
4. **自定义快捷键**：支持用户自定义快捷键组合

## 🔧 技术实现

### 快捷键注册
```cpp
// 注册全局快捷键
RegisterHotKey (hWnd, HOTKEY_ID_TOGGLE_WINDOW, MOD_CONTROL | MOD_ALT, 0x56);  // Ctrl+Alt+V
RegisterHotKey (hWnd, HOTKEY_ID_QUICK_COPY, MOD_CONTROL | MOD_ALT, 0x43);     // Ctrl+Alt+C
```

### 快捷键处理
```cpp
case WM_HOTKEY:
    if (wParam == HOTKEY_ID_TOGGLE_WINDOW)
    {
        // 切换窗口显示/隐藏
    }
    else if (wParam == HOTKEY_ID_QUICK_COPY)
    {
        // 快速复制最近一条记录
    }
```

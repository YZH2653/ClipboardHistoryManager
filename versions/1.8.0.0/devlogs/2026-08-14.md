## 性能瓶颈分析

### 1. GDI 对象频繁创建销毁
- 每个 Draw 函数都调用 CreateFont/DeleteObject
- 每次重绘创建 10+ 个 GDI 对象
- GDI 对象创建开销大，影响绘制性能

### 2. 无双缓冲
- 直接绘制到屏幕 HDC
- 多次 GDI 调用导致闪烁
- 用户看到中间绘制状态

### 3. 记录筛选效率低
- GetFilteredRecords() 每次重绘都调
- 每次都复制全部记录并排序
- 搜索文本未变时也重新计算

### 4. 数据结构效率低
- vector 头部插入是 O(n)
- 搜索时 preview 和 content 重复匹配

# 前端开发需求文档

## 项目概述

使用 Tauri + React + TypeScript + Ant Design 重新设计剪贴板管理器的 UI 界面。

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Tauri | 2.x | 桌面应用框架 |
| React | 18.x | UI 框架 |
| TypeScript | 5.x | 类型安全 |
| Ant Design | 5.x | UI 组件库 |
| Vite | 5.x | 构建工具 |

## 功能需求

### 1. 历史记录页面

- 显示剪贴板历史记录列表
- 支持搜索过滤
- 支持复制、置顶、删除操作
- 支持批量操作
- 显示记录时间

### 2. 设置页面

- 保存时间设置（3天/5天/7天/30天/永久）
- 最大记录数设置
- 快捷键配置
- 开机自启设置
- 最小化到托盘设置

### 3. 关于页面

- 版本信息
- 更新内容
- 快捷键说明
- 作者信息

## UI 设计要求

- 现代化设计风格
- 响应式布局
- 深色模式支持
- 流畅的动画效果
- 良好的用户体验

## 与后端通信

通过 Tauri 的 invoke 机制与 Rust 后端通信：

```
前端 → invoke("get_records") → Rust (rusqlite) → 返回数据
```

# 历史剪贴板管理器

一个轻量级的Windows历史剪贴板管理软件，自动记录您复制的所有内容，方便随时查看和再次使用。

## ✨ 功能特性

- **自动记录**：复制的文字和图片会自动保存到本地
- **历史查看**：按时间倒序显示所有记录，最新复制的内容排在最前面
- **搜索功能**：支持文字搜索和时间搜索（日期、时间、年月）
- **置顶功能**：重要内容可以置顶，固定在列表顶部
- **删除功能**：不需要的记录可以手动删除，支持批量删除
- **快速复制**：点击卡片即可复制内容到剪贴板
- **过期清理**：自动清理超过保留期限的记录
- **系统托盘**：关闭窗口时最小化到系统托盘，双击恢复
- **单实例**：防止重复打开，再次启动时恢复已有窗口
- **设置管理**：保留天数、最大记录数、开机自启等配置

## 🚀 快速开始

### 环境要求

- Windows 7/8/10/11
- [Node.js 18+](https://nodejs.org/) (LTS)
- [Rust](https://rustup.rs/) (通过 rustup 安装)
- [MinGW-w64](https://www.mingw-w64.org/) (GCC 编译器)

### 开发运行

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发模式
npm run tauri dev
```

### 打包发布

```bash
cd frontend
npm run tauri build
```

打包后的文件位于 `frontend/src-tauri/target/release/bundle/`

## 🛠️ 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 前端 UI | React + Ant Design | 界面展示和交互 |
| 桌面框架 | Tauri 2.x | 窗口管理和系统集成 |
| 桥接层 | Rust FFI | 连接前端和 C++ 后端 |
| 后端核心 | C++17 + Win32 API | 剪贴板监听和数据处理 |
| 数据库 | SQLite3 | 本地数据存储 |
| 图片处理 | GDI+ | 截图捕获和保存 |

## 架构

```
React 前端 → Tauri invoke → Rust FFI → C++ 后端
                                    ↓
                              剪贴板监听线程
                              (AddClipboardFormatListener)
                                    ↓
                              SQLite 数据库
```

## ⚙️ 配置说明

- **保留天数**：默认保留最近3天的记录（可选1天/3天/5天/7天/30天/永久）
- **最大记录数**：默认最多保存1000条记录
- **开机自启**：通过 Windows 注册表实现
- **最小化到托盘**：默认开启

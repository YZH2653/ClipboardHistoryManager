# 历史剪贴板管理器

一个轻量级的Windows历史剪贴板管理软件，自动记录您复制的所有内容，方便随时查看和再次使用。

## ✨ 功能特性

- **自动记录**：复制的文字和图片会自动保存到本地
- **历史查看**：按时间倒序显示所有记录，最新复制的内容排在最前面
- **搜索功能**：支持文字搜索和时间搜索（日期、时间、年月）
- **置顶功能**：重要内容可以置顶，固定在列表顶部
- **删除功能**：不需要的记录可以手动删除，支持批量删除
- **快速复制**：点击卡片即可复制内容到剪贴板
- **过期清理**：自动清理超过保留期限的记录
- **设置管理**：保留天数、最大记录数、开机自启等配置
- **便携使用**：绿色软件，无需安装，可直接放在U盘使用

## 🚀 快速开始

### 环境要求

- Windows 7/8/10/11
- [Node.js 18+](https://nodejs.org/) (LTS)
- [Rust](https://rustup.rs/) (通过 rustup 安装)

### 开发运行

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发模式（前端 + Rust 后端热重载）
npm run tauri dev
```

### 打包发布

```bash
cd frontend
npm run tauri build
```

打包后的 `.exe` 文件位于 `frontend/src-tauri/target/release/bundle/`

## 🔍 搜索格式

| 格式 | 示例 | 说明 |
|------|------|------|
| 完整日期 | `2026-05-31` | 搜索指定日期的记录 |
| 短日期 | `05-31` | 搜索月-日的记录 |
| 年月 | `2026-05` | 搜索指定年月的记录 |
| 时间 | `17:10` | 搜索指定时间的记录 |
| 文字 | `剪贴板` | 搜索包含关键词的记录 |

## ⚙️ 配置说明

- **保留天数**：默认保留最近3天的记录（可选3天/5天/7天/30天/永久）
- **最大记录数**：默认最多保存1000条记录
- **开机自启**：通过 Windows 注册表实现
- **最小化到托盘**：默认开启
